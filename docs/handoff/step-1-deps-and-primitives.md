## What landed

Fourteen unmodified shadcn primitive files were copied byte-for-byte from
`mockup/src/components/ui/` into `frontend/src/components/ui/`, plus the
toast hook into `frontend/src/hooks/`. Fourteen new runtime dependencies
were added to `frontend/package.json` at the exact versions in

## Notes / surprises

- None. The 14 primitive files import only from packages now installed

  `Button` reference inside one of the new files) needed to be ported.

  frontend already had for shared deps (`@radix-ui/react-tooltip`,
  `recharts`, `next-themes`, etc.), so there was no version-skew
